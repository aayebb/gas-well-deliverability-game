# Gas Well Deliverability Game

A web-based interactive game simulating gas well deliverability tests. Optimize production, analyze flow rates, and master gas reservoir engineering!

## Overview
Designed as an interactive tool for petroleum engineering education, this simulation allows users to conduct virtual gas well deliverability tests. Players can analyze Inflow Performance Relationship (IPR) curves, evaluate well capabilities, and optimize flow rates based on reservoir parameters.

## Features
* Interactive simulation of gas deliverability testing methods.
* Visual analysis of flow rates and production optimization.
* Built to support engineering students in understanding real-world reservoir mechanics.

## How to Play
You can run the simulation directly in your web browser without any installation.
